# ready_meals_soup: curation and lens-grade rules

Generated by a one-off python script (not in repo; its full logic is written out below). Source pool: `data/products/uk_products.parquet` (Open Food Facts UK). All grades are clamped to 0-1. Every product's `lens_grades.<lens>.why` lists the OFF field values used.

Selection criteria: the product has an OFF image, the highest `scans` within its brand and sub-type, and it adds variety across the lenses. Roles are a curation judgement: incumbent = long-established mass brand, challenger = newer DTC/startup brand, own_label = retailer brand. M&S counts as own-label because M&S only sells its own brand.

## Shared maps (all are assumptions; each is a monotone ordinal-to-0-1 mapping)
- `eco` = ecoscore: a-plus 1, a .85, b .7, c .5, d .3, e .15, f 0, unknown .4. Assumption: unknown is set slightly below the midpoint so missing data is not rewarded.
- `nova_map`: 1→1, 2→.75, 3→.5, 4→0 (OFF `nova`)
- `nutri`: a 1, b .75, c .5, d .25, e 0 (OFF `nutriscore`)
- `a10` = 1 − min(additives_n,10)/10; `a5` = 1 − min(additives_n,5)/5 (OFF `additives_n`)
- organic = `en:organic` in OFF `labels`; vegan = `en:vegan` in OFF labels or analysis; gf = `en:no-gluten` label; palm_free = `en:palm-oil-free` in OFF `analysis`. OFF `palm_oil_n` was empty for this category, so the analysis tag is used instead.
- `ing_count` = number of top-level commas in OFF `ingredients_text`, plus 1. OFF `ingredients_n` was empty for these rows.
- `g` = pack grams from OFF `quantity`. Tideford's quantity is missing, so 600g is assumed (the standard pot size).
- price_gbp = assumption: typical UK RRP in 2026 for that pack size. No retailer page was fetched because retailer pages block bots. Replace these with live URLs if anyone gets one.

## Lens rules
- **eco_low_chemical** = .4·a10 + .3·eco + .2·organic + .1·palm_free
- **upf_avoider_parent** = .5·nova_map + .3·a5 + .2·(1 − min(ing_count,20)/20)
- **glp1_small_appetite** = .4·min(protein_100g/10,1) + .3·min(fiber_100g/4,1) + .3·portion. Portion: ≤400g → 1, ≤600g → .5, else 0. Assumption: smaller packs suit reduced appetite.
- **frugal_unit_price** = 1 − (£/kg − 1.5)/(18 − 1.5). Anchors are assumptions: £1.5/kg is the cheapest own-label tin, £18/kg is a premium chilled meal. Caveat: Itsu is a 64g dry pot, so its £/kg is on dry weight and scores 0.
- **protein_gym** = .7·min(protein_100g/12,1) + .3·min(protein_per_pack/30g,1)
- **protein_sceptic_gimmick_reactant** = .6·(1 − gimmick) + .4·nova_map. gimmick = 1 when the OFF name contains protein|power|immunity|super|goodness AND proteins_100g < 10. Assumption: a "protein" claim on food with under 10 g per 100 g reads as a gimmick to this lens.
- **habit_loyalist_shrinkflation_angry** = .7·familiarity + .3·(pack ≥ 400g). Familiarity: incumbent 1, own_label .6, challenger .2. Assumption: loyalists reward known brands and the standard tin size. OFF has no shrinkflation history.
- **meal_deal_office** = .4·(pack ≤ 460g, single serve) + .3·(price ≤ £3.50, the meal-deal ceiling assumption) + .3·min(protein_100g/8,1)
- **vegan_ethical** = .7·vegan + .2·eco + .1·palm_free
- **allergen_coeliac** = 0 if `en:gluten` is in OFF `allergens`, else .6 + .4·gf (an explicit gluten-free label adds trust)
- **ai_delegator** = .4·nutri + .3·nova_map + .3·completeness. Assumption: an LLM shopping agent ranks on Nutri-Score/NOVA and on how much structured data it can read.
- **novelty_seeker_tiktok** = .5·(role = challenger) + .3·novel_flavour + .2·(1 − min(scans/100,1)). novel_flavour is a regex on name and ingredients: dhal|daal|satay|harissa|buddha|thai|miso|ramen|gyoza|chipotle|teriyaki. Fewer OFF scans means less mainstream.

## Known gaps (stated, not hidden)
- No NOVA 1 or 2 products: every OFF-UK soup or ready meal with an image is NOVA 3 or 4. Within the category, the variety is NOVA 3 versus 4.
- No product contains sweeteners: none of the OFF soups or ready meals in this pool list any. Sweetener variety comes from other units.
